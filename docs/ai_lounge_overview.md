# AI Lounge 기능 소개

AI Lounge는 사내 AI 활용을 과제 발굴, 데이터 준비, 자산 재사용, 코드 개발, 지식 공유까지 하나의 흐름으로 연결하는 포털입니다. 개인이나 팀 단위로 끝나는 AI 실험을 조직이 재사용할 수 있는 자산으로 전환하고, 현업 구성원이 더 쉽게 AI 기반 업무 개선을 시작하도록 돕는 것을 목표로 합니다.

## 소개 및 강점

AI Lounge의 핵심 강점은 AI 업무의 전 과정을 한곳에서 다룬다는 점입니다. 현업 문제를 정의하고, 필요한 데이터와 자산을 찾고, 노트북으로 검증한 뒤, 결과와 경험을 커뮤니티에 공유하는 순환 구조를 제공합니다.

- **전사 AI 자산화**: 우수 프로젝트, 모델, 코드, 데이터 스키마, 운영 노하우를 표준화해 재사용 가능한 자산으로 축적합니다.
- **현업 친화적 접근**: 검색, 필터, 대화형 Agent, 노트북, 제안 폼 등 익숙한 UI를 통해 비전문가도 AI 과제를 구체화할 수 있습니다.
- **중복 개발 감소**: 이미 검증된 AI 자산과 공개 노트북을 탐색하고 포크해 새 과제에 빠르게 적용할 수 있습니다.
- **협업과 확산 중심**: 팀 노트북, 오픈랩, 블로그, 기술 뉴스, 제안 게시판을 통해 개인의 경험을 조직 지식으로 확산합니다.
- **개발 환경 진입 장벽 완화**: 별도 설치 없이 브라우저에서 노트북을 열고, Vibe Coding AI로 코드 생성과 수정을 지원합니다.

## 세부 기능

### Data Studio

Data Studio는 AI 과제 수행에 필요한 데이터를 탐색하고 적재 요청을 관리하는 영역입니다.

- **데이터 탐색**: 사내에서 활용 가능한 데이터셋을 검색하고 업무 목적에 맞는 데이터 후보를 확인하는 공간입니다.
- **데이터 적재 요청**: 분석이나 모델 개발에 필요한 데이터를 플랫폼에 적재하도록 요청하는 창구입니다.
- **향후 역할**: AI Studio의 자산 탐색, Code Studio의 노트북 개발과 연결되어 데이터 준비부터 실험까지 이어지는 기반 영역이 됩니다.

> 현재 mockup에서는 Data Studio의 상세 화면이 준비 중 상태로 표시됩니다.

### AI Studio

AI Studio는 AI Lounge의 중심 영역으로, AI 과제 발굴과 AI 자산 탐색을 담당합니다.

- **DX 과제 발굴**: AI Agent와 대화하며 현업 문제를 구체화하고, 과제 정의서와 참고 자산을 자동 생성합니다.
- **AI 자산 탐색**: 전사 AI 프로젝트와 산출물을 카탈로그 형태로 검색합니다.
- **태그 및 키워드 검색**: 자산명, 설명, 태그 기반 검색과 업무 영역, Task, Data 유형, 구현 방식 등의 필터를 제공합니다.
- **정렬 및 비교**: 재사용순, 최신순, 운영성숙도 기준으로 자산을 정렬하고, 여러 프로젝트를 비교할 수 있습니다.
- **자산 상세 정보**: 입력/출력 스키마, 파일 구성, 모델/코드 정보, 기대 효과, 운영 정보 등을 확인할 수 있습니다.
- **내 컬렉션**: 관심 있는 자산을 모아두고 이후 재사용 후보로 관리합니다.

### Code Studio

Code Studio는 브라우저 기반 노트북 개발 환경과 AI 코딩 보조 기능을 제공하는 영역입니다.

- **소개**: 설치 없이 브라우저에서 Python/R 노트북을 열고 실행할 수 있는 개발 공간입니다.
- **내 워크스페이스**: 개인 노트북 목록을 관리하고, 선택한 노트북을 셀 단위로 편집·실행합니다.
- **Vibe Coding**: 자연어로 코드 생성을 요청하면 AI가 코드를 제안하고, 현재 선택한 셀에 바로 삽입할 수 있습니다.
- **셀 기반 편집**: 코드 셀을 추가하고, 기존 셀을 직접 수정하며, 분석 흐름을 노트북 형태로 구성합니다.
- **팀 노트북**: 팀 또는 부서가 공유한 노트북을 탐색하고 포크해 활용합니다.
- **오픈랩**: 전사 공개 노트북을 찾아보고 내 워크스페이스로 가져와 재사용합니다.
- **지식 내재화**: 개인의 실험과 구현 노하우를 팀과 전사의 재사용 가능한 개발 자산으로 축적합니다.

### AX Community

AX Community는 AI 전환 경험과 아이디어를 공유하고 확산하는 커뮤니티 영역입니다.

- **Tech News**: 생성형 AI, 제조 AI, MLOps, DX 전략 등 최신 기술 동향과 적용 사례를 큐레이션합니다.
- **AI Blog**: 구성원이 현업 적용 경험, 실패와 교훈, 재사용 팁을 직접 작성하고 공유합니다.
- **Gen AI Proposal**: 현업에서 생성형 AI로 해결하고 싶은 문제를 제안하고, 검토 상태와 채택 여부를 관리합니다.
- **참여 기반 확산**: 읽기, 제안, 공유, 댓글, 조회 등의 활동을 통해 AI 활용 경험을 조직 전체로 전파합니다.

## 기능 흐름 예시

1. AX Community에서 유사 사례나 기술 동향을 확인합니다.
2. AI Studio의 DX 과제 발굴 Agent로 현업 문제를 과제 정의서로 구체화합니다.
3. Data Studio에서 필요한 데이터 후보를 찾거나 적재를 요청합니다.
4. AI Studio의 자산 카탈로그에서 재사용 가능한 모델, 코드, API 스펙을 탐색합니다.
5. Code Studio에서 노트북을 열어 데이터를 분석하고 Vibe Coding으로 코드를 빠르게 작성합니다.
6. 완성된 노트북과 적용 경험을 팀 노트북, 오픈랩, AI Blog로 공유합니다.

## 요약

AI Lounge는 단순한 AI 프로젝트 목록이 아니라, 현업 문제 발굴부터 데이터 준비, 자산 탐색, 코드 개발, 조직 공유까지 이어지는 사내 AI 실행 플랫폼입니다. 네 가지 스튜디오와 커뮤니티 영역이 연결되면서 AI 활용을 개인 역량이 아닌 조직 역량으로 확장하는 구조를 제공합니다.
